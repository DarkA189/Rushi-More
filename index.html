Code Review Sentinel

Production · 30K+ reviews / month

A code review platform pairing Semgrep static analysis with LLM inference to catch both real security issues and the things models invent, fabricated function signatures, calls to standard library functions that don't exist, misused crypto primitives.

It grew to 30,000+ reviews a month on a free hosting tier without any marketing. The hard part wasn't the model call; it was everything around it. LLM output isn't reliably parseable, so I built a five-stage recovery pipeline that degrades gracefully instead of failing, and attached confidence bands to every finding so nothing is presented as more certain than it is.

Self-hosted vs API inference

Benchmarking study

Sentinel's API costs started climbing with volume. Instead of guessing whether self-hosting would be cheaper, I built the harness to answer it.

Load-tested concurrent inference across batch sizes 1–64 with async request scheduling, profiled p50/p95/p99 latency, and compared quantization schemes — FP16, INT8, AWQ, GPTQ — to find configurations that held output quality while cutting GPU memory by roughly 60%. The result was a cost model showing the real crossover point between self-hosted and per-token API serving, plus a fallback path that removed a hard dependency on one provider's rate limits.

IssueForge

Full-stack SaaS

Ingests GitHub issues through OAuth, runs LLM-driven root-cause analysis, and returns structured, developer-ready pull request drafts rather than a wall of prose.

The part I care about most is the feedback loop: it captures the edits users actually make to generated output and uses them to re-weight future prompts. AI output is a first draft, the system should learn from being corrected, not assume it was right.

Off the clock

The part that doesn't fit on a resume.

What actually pulls me in is a problem that hasn't been solved yet, and I've never been picky about the category. An appliance that has stopped working, something mechanical that's out of alignment, a query that's slow for reasons nobody can explain, a pipeline quietly dropping records, they all scratch the same itch. Take it apart, find where the assumption broke, put it back together better than it was. Most of what I've built professionally started exactly that way.

Outside of that, I'm at the gym most days, it's the one hour where the problem is simple and the feedback is immediate. Weekends usually mean tennis or pickleball, whenever I can get a court. When I want to think without a screen, I sketch.

I'm also a serious eater. Trying a cuisine I've never had is one of my favourite ways to spend an evening, and it's part of why I like living where I do. On the same thread, I speak English and Hindi, and I'm working my way through Japanese and Spanish, slowly, badly, and with real enjoyment.
